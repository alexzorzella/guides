### NPM

[NPM Docs](https://docs.npmjs.com/)

On a new machine:
```bash
sudo apt install nodejs npm && npm install astro && npm audit fix
```

Serving the content locally:
```bash
npm run dev
```

### HTTP Python Server

```bash
python -m http.server --bind 127.0.0.1
# or
uv run python -m http.server --bind 127.0.0.1
```

The content will be served to `http://localhost:8000/`.

To allow computers on the same private network, use

```bash
python -m http.server
# or
uv run python -m http.server
```

this binds to `0.0.0.0`, allowing anyone on your private network to access the files and folders in the working directory.
