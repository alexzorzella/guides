If you intend on using ResourceLoader, make sure to have both the corresponding ResourceLoader object in a /Resources/ folder in your project.

ResourceLoader is a self-instantiating static singleton. It does not have to be manually dragged into the scene view.

## Functions

## static GameObject LoadObject

|Parameter|Description|Default|
|:---|:---|:---:|
|Parameter|Description|Default|

Returns an object named objectName found in any Resources folder. If specified, the function will look into a subfolder. Multiple subfolders are supported. A slash is not required for the deepest folder.

## static GameObject InstantiateObject

|Parameter|Description|Default|
|:---|:---|:---:|
|string objectName|The name of the object||
|Transform parent|The object that the instantiated object will be parented to (optional)|null|

Instantiates an object with the passed name at the origin with no rotation if one is found.

## static GameObject InstantiateObject

|Parameter|Description|Default|
|:---|:---|:---:|
|string objectName|The name of the object||
|Vector3 position|The position that the object will be instantiated||
|Quaternion rotation|The rotation that the object will be instantiated at||
|Transform parent|The object that the instantiated object will be parented to (optional)|null|

Instantiates an object with the passed name at the given position with the given rotation if one is found. If a parent transform is passed, it instantiates it parented to that object. Instantiates an object with the passed name at the given position with the given rotation if one is found. If a parent transform is passed, it instantiates it parented to that object.

## static T LoadFile\<T\>

|Parameter|Description|Default|
|:---|:---|:---:|
|string filename|The name of the file to be loaded||
|string subfolder|The subfolder within a /Resources/ folder where the file is located|""|

Returns an object of type T named filename found in any Resources folder. If specified, the function will look into a subfolder. Multiple subfolders are supported. A slash is not required for the deepest folder.

## static Sprite LoadSprite

|Parameter|Description|Default|
|:---|:---|:---:|
|string mainTexture|The name of the main texture containing multiple sprites||
|string subtextureName|The name of the subtexture that will be returned||
|string subfolder|The subfolder within a /Resources/ folder where the sprite is located|""|

Returns a subtexture Sprite named subtextureName whose parent Sprite is named mainTexture found in any Resources folder. If specified, the function will look into a subfolder. Multiple subfolders are supported. A slash is not required for the deepest folder.
