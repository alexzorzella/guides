If you intend on using GnaTransition, make sure to have both the corresponding GnaTransition object and LeanTween in your project.

GnaTransition is a self-instantiating static singleton. It does not have to be dragged into the scene view yourself.

# Usage

Typical GnaTransition usage looks like

```csharp
// Say there are four scenes in the following order: Startup, MainMenu, Level, and Credits

public void LoadLevelByName() {
    GnaTransition.LoadScene("Level");
}

public void LoadCreditsByIndex() {
    GnaTransition.LoadScene(3);
}

public void QuitGame() {
    GnaTransition.Quit();
}
```

# Functions

## void LoadScene
Loads the scene with the passed name.

|Parameter|Description|Default|
|:---|:---|:---:|
|string sceneName|The name of the scene to load||

## void LoadScene
Loads the scene with the passed build index.

|Parameter|Description|Default|
|:---|:---|:---:|
|int sceneIndex|The index of the scene to load||

## Teardown
Runs before the scene is transitioned. If anything should run every time a new scene is loaded, before that scene is loaded, put it here. Note: In the future, this may become an event that an external Bootstrap/Teardown function can listen to.

## Bootstrap
Runs after the scene is transitioned. If anything should run every time a new scene is loaded, after that scene is loaded, put it here. Same note as above.

## void Quit
Fades the screen to black and quits the application.
