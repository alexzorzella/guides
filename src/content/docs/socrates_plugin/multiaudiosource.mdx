MultiAudioSource is a utility class that can be used to play audio clips. 

## Audio

Put audio clips in any Resources folder (Assets/Resources, Assets/Audio/Resources, Assets/Audio/Cutscenes/Resources). If there are multiple clips of the same sound for variation (like various footsteps), they should be named with a suffix `_n` where `n` is 0 indexed and ascending continuously `clip_name_0`, `clip_name_1`, ..., `clip_name_n`.

## Usage

Say there is a Monobehaviour class `Cat` that wants to play `eat.mp3` every time it eats food. At some point before the first usage of any play function, the MultiAudioSource should be initialized using one of the two initialization functions, `FromResource` and `FromResources`. It can then be played any number of times later using any of the play functions `PlayRoundRobin()`, `Play()`, `PlayRandom()`, and `PlayOnlyIfDone()`.

```csharp
public class Cat : Monobehaviour {
    MultiAudioSource eatAudio;
    
    public void Start() {
        eatAudio = MultiAudioSource.FromResource(gameObject, "eat");
    }
    
    // ...    
    
    // Called from somewhere
    void Eat() {
        audio.Play(); 
    }
}
```

If there are multiple audio clips that should be added to the pool, like `eat_0.mp3`, `eat_1.mp3`, and `eat_2.mp3`, use `FromResources` instead.

```csharp
public class Cat : Monobehaviour {
    MultiAudioSource eatAudio;
    
    public void Start() {
        // There are three eat_n.mp3 audio clips, so count is 3
        eatAudio = MultiAudioSource.FromResources(gameObject, "eat", 3);
    }
    
    // ...    
    
    // Called from somewhere
    void Eat() {
        audio.PlayRandom();
    }
}
```

## Functions
Instances of MultiAudioSource can only be constructed through the FromResource() and FromResources() functions, its constructor is private.

### string GetName
Returns the name of the clip loaded into the first audio source.
	
### void SetVolume
Sets the volume of all the sources to the passed volume.

### void SetPitch
Sets the pitch of all the audio sources to the passed pitch.
	
### void RandomizePitches

|Parameter|Description|Default|
|:---|:---|:---:|
|`float` minPitch|The minimum pitch to be randomly selected|0.8|
|`float` maxPitch|The maximum pitch to be randomly selected|1.2|

Randomly sets the pitch of all the audio sources to a pitch between `minPitch` and `maxPitch`.

### void PlayRoundRobin 
Plays the next audio clip in the rotation of loaded clips.

### void Play 
An alias for PlayRoundRobin
	
### void PlayRandom 
Plays a random audio clip from the rotation loaded clips.

### bool IsPlaying
Returns true if at least one of the audio sources in the pool of sources is playing.

### void PlayOnlyIfDone 
Plays a random audio clip from the rotation of loaded clips if none of the sources are currently playing.

### void Stop 
Stops all the audio sources.

### static MultiAudioSource FromResource

|Parameter|Description|Default|
|:---|:---|:---:|
|`GameObject` gameObject|The object that the AudioSource component will be attached to.||
|`string` path|The name of the audio clip||
|`bool` loop|Whether the audio should loop indefinitely when played|false|
|`string` audioMixer|The mixer that the audio will play from|SFX|
|`float` volume|The volume that the audio will be played at|1|
|`float` pitch|The pitch that the audio should be played at|1|
|`float` spatialBlend|The [spatial blend](https://docs.unity3d.com/ScriptReference/AudioSource-spatialBlend.html) of the audio source|0|
|`float` minDistance|The audio source's [mininum distance](https://docs.unity3d.com/ScriptReference/AudioSource-minDistance.html). Only set if spatialBlend > 0|0|
|`float` maxDistance|The audio source's [maximum distance](https://docs.unity3d.com/ScriptReference/AudioSource-maxDistance.html). Only set if spatialBlend > 0|0|
|`float` dopplerLevel|The audio source's [doppler level](https://docs.unity3d.com/ScriptReference/AudioSource-dopplerLevel.html). Only set if spatialBlend > 0|1|

Loads a single audio clip from the given `path`. This is a relative path to any directory named `Resources` within the `Assets` directory tree (i.e. it may be in Assets/Resources, Assets/Audio/Resources, Assets/Audio/Cutscenes/Resources). The `AudioSource` component is added to the passed `gameObject`. Typically, the `gameObject` will be the `this.gameObject` from the method's caller. There may be cases where a static script wants to use a MultiAudioSource. In that case, the passed gameObject should have the same lifetime as the method's caller. Do not pass a static, persistent, and/or singleton GameObject to `gameObject` if `FromResource` is being called from an object that won't live as long or longer than `gameObject`. This may lead to a large number of unused AudioSources that take up resources.

This method throws if the resource does not exist.

### static MultiAudioSource FromResources

|Parameter|Description|Default|
|:---|:---|:---:|
|`GameObject` gameObject|The object that the AudioSource component will be attached to.||
|`string` pathPrefix|The name of the audio clip, not including the number `_n`||
|`int` count|The total number of audio clips in that pool of clips||
|`bool` loop|Whether the audio should loop indefinitely when played|false|
|`float` volume|The volume that the audio will be played at|1|
|`float` pitch|The pitch that the audio should be played at|1|
|`float` spatialBlend|The [spatial blend](https://docs.unity3d.com/ScriptReference/AudioSource-spatialBlend.html) of the audio source|0|
|`float` minDistance|The audio source's [mininum distance](https://docs.unity3d.com/ScriptReference/AudioSource-minDistance.html). Only set if spatialBlend > 0|0|
|`float` maxDistance|The audio source's [maximum distance](https://docs.unity3d.com/ScriptReference/AudioSource-maxDistance.html). Only set if spatialBlend > 0|0|
|`float` dopplerLevel|The audio source's [doppler level](https://docs.unity3d.com/ScriptReference/AudioSource-dopplerLevel.html). Only set if spatialBlend > 0|1|

This is like `FromResource`, but for loading multiple audio clips (say to be played randomly or in a round-robin fashion). `count` denotes how many clips to load. The expected file names are `pathPrefix_0`, `pathPrefix_1`, ... `pathPrefix_{count - 1}`.

This method throws if any of the resources does not exist.
