While writing the names and contents of dialogue, the following tags can be used to add flavor:

|Tag|Description|
|:---|:---|
|`[wave,INT]This text will wave[!wave]`|Makes the surrounded text wave with the passed INT overriding the default amplitude|
|`[shake,INT]This text will shake[!shake]`|Makes the surrounded text shake with the passed INT overriding the default intensity|
|`This text is displayed before the delay[delay,FLOAT][!delay] and this text is displayed FLOAT seconds after!`|Pauses the text as it appears for FLOAT seconds|
|`[gradient]This text will have a scrolling gradient specified in DialogueGradient[!gradient]`|Makes the surrounded text have a scrolling gradient (which by default is a rainbow)|

Socrates Markdown works with [TextMeshPro Rich Text](https://docs.unity3d.com/Packages/com.unity.textmeshpro@4.0/manual/RichText.html).

## (interface) SocratesTextListener

Register `SocratesTextListener`s to instances of `SocratesText` for that class to be notified when the `SocratesText` has been fully displayed.

## SocraticAnnotation

SocraticAnnotation is a self-instantiating static singleton. It does not have to be manually dragged into the scene view.

It contains various variables that specify what characters define Socrates Markdown Language as well as shake, wave, delay, and gradient intensities, amplitudes, delays, multipliers, and speeds.

## DialogueGradients

A self-instantiating singleton object that stores the gradients used by the dialogue system. To add more gradients to the collection of available gradients, make a publicly facing gradient and add it in `Initialize` (or make one in the `Initialize` function itself, but in this instance the Unity editor provides a window that makes it easy to edit the gradient.)

### Gradient GetGradient

|`string` gradientName|The name associated with the desired gradient in the gradient map||
