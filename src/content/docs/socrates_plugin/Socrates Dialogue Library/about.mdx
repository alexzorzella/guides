The Socrates Dialogue Library includes four distinct systems: Socrates Dialogue, Socrates Markdown Language, SocraTSV, and SocraGUI.

Socrates Dialogue is a facet based dialogue system that exists to create conversations.

Socrates Markdown Language adds the ability to have waves, shaking, delays, and rainbow to text as it is displayed.

SocraTSV converts dialogue written in a tsv file to dialogue in the Socrates Dialogue format.

SocraGUI is a dialogue GUI that uses events from a dialogue manager to display a conversation on the screen.

These four systems can be used in a variety of combinations.
